TEAM PROJECT

THERMX

A thermal-event monitoring project using NASA FIRMS satellite data to identify heat activity and investigate where and why it is occurring.

OVERVIEW

About the Project

THERMX is a team project focused on monitoring thermal activity and investigating potential sources of unusual heat.

The project integrates real satellite-based thermal-event data from NASA's Fire Information for Resource Management System (FIRMS).

By presenting this information through a dashboard and map-based interface, THERMX aims to help users explore where thermal events are detected and investigate possible reasons behind them.

DATA & TECHNOLOGY

How It Works

  • Uses NASA FIRMS satellite thermal-event data.
  • Displays detected events through a map-based interface.
  • Helps users explore the geographic locations of thermal activity.
  • Organises event information in a dashboard.
  • Supports investigation of possible sources of detected heat.

OBJECTIVE

Purpose of the Project

The objective of THERMX is to make satellite-based thermal information easier to explore and understand. It aims to support investigation through real data rather than relying on fabricated thermal-event records.

MY EXPERIENCE

Working on THERMX

Working on THERMX provided experience in integrating external data sources, building dashboard interfaces, and presenting geospatial information as part of a collaborative technical project.
